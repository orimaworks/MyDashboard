🎨 ANSI Escape Codes

Les séquences ANSI permettent de modifier l'apparence du texte dans un terminal : couleur, style, arrière-plan, curseur, effacement, etc.

🧩 Structure

\033[CODE;CODEmTexte\033[0m
  • \033[ → début de la séquence ANSI
  • ; → sépare plusieurs codes
  • m → applique les codes de couleur/style
  • \033[0m → réinitialise la mise en forme

⚠️ Attention : ce n'est pas 1033[ et les codes sont séparés par ;, pas par des virgules.

🎨 Couleurs du texte

  • 30 → Noir
  • 31 → Rouge
  • 32 → Vert
  • 33 → Jaune
  • 34 → Bleu
  • 35 → Magenta
  • 36 → Cyan
  • 37 → Blanc
  • 39 → Couleur par défaut
print("\033[31mRouge\033[0m")
print("\033[32mVert\033[0m")
print("\033[33mJaune\033[0m")
print("\033[34mBleu\033[0m")
print("\033[35mMagenta\033[0m")
print("\033[36mCyan\033[0m")

💡 Styles

  • 0 → Reset
  • 1 → Gras
  • 2 → Faible / atténué
  • 3 → Italique
  • 4 → Souligné
  • 5 → Clignotant
  • 7 → Inversion avant/arrière-plan
  • 9 → Barré
  • 22 → Désactive le gras/atténué
  • 23 → Désactive l'italique
  • 24 → Désactive le soulignement
  • 25 → Désactive le clignotement
  • 27 → Désactive l'inversion
  • 29 → Désactive le barré
print("\033[1mGras\033[0m")
print("\033[3mItalique\033[0m")
print("\033[4mSouligné\033[0m")
print("\033[5mClignotant\033[0m")
print("\033[7mInversé\033[0m")

🎯 Combiner plusieurs effets

Plusieurs codes peuvent être combinés dans une même séquence en les séparant par ;. 

print("\033[1;31mERREUR\033[0m")
print("\033[1;33mAVERTISSEMENT\033[0m")
print("\033[1;32mSUCCÈS\033[0m")

Ici :

  • 1 → gras
  • 31 → rouge
  • 33 → jaune
  • 32 → vert

🔢 Couleurs 256

Certains terminaux supportent une palette de 256 couleurs. 

print("\033[38;5;208mOrange\033[0m")
print("\033[38;5;202mOrange foncé\033[0m")
print("\033[38;5;39mBleu\033[0m")
  • 38;5;n → couleur du texte
  • 48;5;n → couleur d'arrière-plan
  • n → valeur comprise entre 0 et 255

🎨 RGB — True Color

Les terminaux compatibles True Color permettent d'utiliser environ 16 millions de couleurs. 

print("\033[38;2;255;100;50mOrange personnalisé\033[0m")
print("\033[48;2;30;30;30mFond personnalisé\033[0m")
  • 38;2;R;G;B → couleur du texte
  • 48;2;R;G;B → couleur du fond
  • R, G, B → valeurs de 0 à 255

🧹 Contrôle du terminal

  • \033[2J → efface l'écran
  • \033[H → place le curseur en haut à gauche
  • \033[K → efface jusqu'à la fin de la ligne
print("\033[2J\033[H")
print("Écran nettoyé")

⬆️ Curseur

  • \033[nA → déplacer le curseur de n lignes vers le haut
  • \033[nB → vers le bas
  • \033[nC → vers la droite
  • \033[nD → vers la gauche
print("Ligne 1")
print("Ligne 2")
print("\033[1A")
print("\033[2K")
print("Ligne remplacée")

💡 Astuce Python

Pour éviter de répéter les séquences ANSI partout dans le code, crée des constantes. 

RESET = "\033[0m"

RED = "\033[31m"
GREEN = "\033[32m"
YELLOW = "\033[33m"
CYAN = "\033[36m"

BOLD = "\033[1m"

print(f"{BOLD}{RED}ERROR{RESET}: fichier introuvable.")
print(f"{BOLD}{GREEN}SUCCESS{RESET}: opération terminée.")

⚠️ Attention

  • \033[0m doit généralement être placé après le texte pour éviter de colorer les messages suivants.
  • Le support des séquences ANSI dépend du terminal utilisé.
  • Le clignotement (5) peut être ignoré par certains terminaux.
  • Les couleurs 256 et RGB nécessitent un terminal compatible.
  • Les codes ANSI servent à l'affichage : ils ne modifient pas le contenu de la chaîne.

🔗 Le pipeline |

Le pipeline permet d'envoyer le résultat d'une commande vers une autre. PowerShell transmet principalement des objets, et non simplement du texte. 

Get-Process | Where-Object CPU -gt 100
Get-Process | Sort-Object CPU -Descending
Get-Process | Select-Object Name, CPU
Get-Service | Where-Object Status -eq "Running"

🔍 Filtrer

Get-Process | Where-Object CPU -gt 100

Version avec la variable automatique $_ :

Get-Process | Where-Object { $_.CPU -gt 100 }

📋 Sélectionner des propriétés

Get-Process | Select-Object Name, CPU, Id

↕️ Trier

Get-Process | Sort-Object CPU -Descending

📊 Regrouper

Get-Process | Group-Object Company

🔢 Compter / mesurer

🧠 Comprendre les objets PowerShell

On peut ensuite enchaîner les opérations : 

Get-Process |
    Where-Object CPU -gt 100 |
    Sort-Object CPU -Descending |
    Select-Object -First 10 Name, CPU, Id

🎯 WHERE

  • WHERE
  • AND / OR / NOT
  • LIKE 'ABC%' → commence par
  • LIKE '%ABC' → termine par
  • LIKE '%ABC%' → contient
  • IN (...)
  • NOT IN (...)
  • BETWEEN ... AND ...
  • IS NULL / IS NOT NULL
SELECT *
FROM users
WHERE nom LIKE '%DUPONT%'
  AND actif = 1;

📊 TRI & LIMITES

  • ORDER BY colonne ASC → tri croissant
  • ORDER BY colonne DESC → tri décroissant
  • FETCH FIRST n ROWS ONLY → limite le nombre de lignes retournées
  • OFFSET n ROWS FETCH NEXT n ROWS ONLY → ignore n lignes puis récupère les suivantes
SELECT *
FROM users
ORDER BY nom ASC
FETCH FIRST 10 ROWS ONLY;

📦 GROUP BY

  • GROUP BY colonne → regroupe les lignes selon une ou plusieurs colonnes
  • HAVING → filtre les groupes après agrégation
  • COUNT() → compte le nombre de lignes ou de valeurs
  • SUM() → calcule la somme des valeurs
  • AVG() → calcule la moyenne des valeurs
  • MIN() / MAX() → retourne la valeur minimale / maximale
SELECT
    ville,
    COUNT(*) AS nombre_users
FROM users
GROUP BY ville
HAVING COUNT(*) > 1
ORDER BY nombre_users DESC;

🔗 JOINTURES

  • INNER JOIN → retourne uniquement les lignes ayant une correspondance dans les deux tables
  • LEFT JOIN → conserve toutes les lignes de la table de gauche, même sans correspondance
  • RIGHT JOIN → conserve toutes les lignes de la table de droite, même sans correspondance
  • FULL OUTER JOIN → conserve toutes les lignes des deux tables, avec ou sans correspondance
  • LEFT JOIN ... IS NULL → recherche les lignes de gauche qui n'ont aucune correspondance à droite
SELECT
    d.id,
    d.nom
FROM demandeurs d
LEFT JOIN users u
    ON u.nom = d.nom
WHERE u.id IS NULL;

🧠 SOUS-REQUÊTES

  • IN (SELECT ...)
  • EXISTS
  • NOT EXISTS
  • WITH nom AS (...) → CTE
SELECT *
FROM users u
WHERE u.id IN (
    SELECT demandeur_id
    FROM demandes
);

🔎 EXISTS / NOT EXISTS

  • EXISTS → vérifier qu'une correspondance existe
  • NOT EXISTS → vérifier qu'aucune correspondance n'existe
SELECT *
FROM users u
WHERE NOT EXISTS (
    SELECT 1
    FROM demandes d
    WHERE d.user_id = u.id
);

📝 INSERT / UPDATE / DELETE

  • INSERT INTO ... VALUES (...)
  • UPDATE ... SET ... WHERE ...
  • DELETE FROM ... WHERE ...
  • ⚠️ Toujours tester le WHERE avec un SELECT
-- Tester avant modification
SELECT *
FROM users
WHERE id = 42;

-- Modifier
UPDATE users
SET actif = 0
WHERE id = 42;

  • ROLLBACK;
  • SAVEPOINT nom;
  • ROLLBACK TO nom;
UPDATE users
SET actif = 0
WHERE id = 42;

COMMIT;

⚡ SPÉCIFIQUE ORACLE

  • DUAL → table système virtuelle utilisée pour exécuter une expression sans table source
  • SYSDATE → retourne la date et l'heure actuelles du serveur Oracle
  • SYSTIMESTAMP → retourne la date et l'heure actuelles avec précision et fuseau horaire
  • USER → retourne le nom de l'utilisateur Oracle actuellement connecté
  • ROWNUM → attribue un numéro aux lignes retournées par une requête
  • FETCH FIRST n ROWS ONLY → limite le nombre de lignes retournées par la requête
SELECT
    USER AS schema_connecte,
    SYSDATE AS date_actuelle,
    SYSTIMESTAMP AS timestamp_actuel
FROM DUAL;

📅 DATES

  • TO_DATE() → convertit une chaîne de caractères en valeur de type date
  • TO_CHAR() → convertit une date ou une valeur en chaîne formatée
  • TRUNC() → supprime l'heure d'une date ou tronque une date selon une unité donnée
  • ADD_MONTHS() → ajoute ou soustrait un nombre de mois à une date
  • MONTHS_BETWEEN() → calcule le nombre de mois entre deux dates
SELECT
    date_creation,
    TO_CHAR(date_creation, 'DD/MM/YYYY') AS date_formatee,
    ADD_MONTHS(date_creation, 1) AS mois_suivant
FROM demandes;

	/*
		YYYY → année
		MM → mois
		DD → jour
		HH24 → heure sur 24 h
		MI → minutes
		SS → secondes
		(Pour remplacer ":" par "h" par exemple, concaténer avec des guillemets doubles : 'HH24"h"MI "et" SS"s"')
	*/

🔤 FONCTIONS TEXTE

  • UPPER() → convertit le texte en majuscules
  • LOWER() → convertit le texte en minuscules
  • INITCAP() → met la première lettre de chaque mot en majuscule
  • TRIM() → supprime les espaces au début et à la fin du texte
  • SUBSTR() → extrait une portion d'une chaîne de caractères
  • INSTR() → recherche la position d'un texte dans une chaîne
  • REPLACE() → remplace une chaîne de caractères par une autre
  • LENGTH() → retourne le nombre de caractères d'une chaîne
SELECT
    UPPER(nom) AS nom_majuscule,
    LOWER(email) AS email_minuscule,
    LENGTH(nom) AS longueur_nom
FROM users;

🧮 CONVERSIONS

  • TO_CHAR() → convertit une valeur en chaîne de caractères, avec possibilité de la formater
  • TO_NUMBER() → convertit une chaîne de caractères en nombre
  • TO_DATE() → convertit une chaîne de caractères en date selon un format donné
  • CAST() → convertit une valeur d'un type de données vers un autre type
SELECT
    TO_CHAR(id) AS id_texte,
    CAST(id AS VARCHAR2(20)) AS id_converti
FROM users;

🧩 VALEURS NULL

  • NVL() → remplace une valeur NULL par une valeur de remplacement
  • NVL2() → retourne une valeur si l'expression n'est pas NULL, et une autre si elle l'est
  • COALESCE() → retourne la première valeur non NULL parmi plusieurs expressions
  • NULLIF() → retourne NULL si deux expressions sont égales, sinon retourne la première
SELECT
    nom,
    NVL(email, 'Non renseigné') AS email
FROM users;

🎨 CONDITIONS

  • CASE WHEN ... THEN ... END
  • DECODE() → spécifique Oracle
SELECT
    nom,
    CASE
        WHEN actif = 1 THEN 'Actif'
        WHEN actif = 0 THEN 'Inactif'
        ELSE 'Inconnu'
    END AS statut
FROM users;

📈 FONCTIONS ANALYTIQUES

  • ROW_NUMBER() → attribue un numéro unique à chaque ligne selon un ordre défini
  • RANK() → attribue un rang aux lignes, en laissant des rangs vides en cas d'égalité
  • DENSE_RANK() → attribue un rang aux lignes, sans laisser de rang vide en cas d'égalité
  • OVER() → définit la fenêtre de lignes sur laquelle s'applique la fonction analytique
  • PARTITION BY → divise les lignes en groupes indépendants pour appliquer la fonction analytique à chacun
SELECT
    nom,
    ville,
    ROW_NUMBER() OVER (
        PARTITION BY ville
        ORDER BY nom
    ) AS numero
FROM users;

📑 CTE — WITH

ORDER BY nom;

Les fonctions

  • calc()
    Effectue un calcul entre différentes unités (+, -, *, /).
    Exemple :

  • min()
    Retourne la plus petite des valeurs fournies.
    Exemple :

  • max()
    Retourne la plus grande des valeurs fournies.
    Exemple :

    Limite une valeur entre un minimum et un maximum.
    Équivalent à max(min, min(valeur, max)).
    Exemple :
    width: clamp(100px, 10em, 200px);

📱 Responsivité (Responsive Design)

  • Définition
    La responsivité est la capacité d'un site web à s'adapter automatiquement aux différentes tailles d'écran (smartphone, tablette, ordinateur...).
  • Mobile First
    Aujourd'hui, la majorité de la navigation se fait sur smartphone. Il est donc recommandé de concevoir d'abord l'interface pour les petits écrans, puis de l'adapter progressivement aux écrans plus larges.
  • Objectifs
    • Améliorer l'UX (User Experience)
    • Faciliter l'accessibilité
    • Optimiser la lisibilité
    • Adapter la disposition des éléments selon l'espace disponible
  • Bonnes pratiques
    • Utiliser des unités relatives (%, vw, vh, rem, em)
    • Éviter les dimensions fixes lorsque c'est possible
    • Utiliser flexbox ou grid
    • Tester sur plusieurs tailles d'écran
  • Media Query
    Permet d'appliquer des règles CSS uniquement sous certaines conditions (largeur, orientation, résolution...). 
    @media (max-width: 768px) {
    /* CSS spécifique mobile */
}

Une couleur HSL se compose de 3 valeurs : hsl(H, S, L) H = Hue (teinte) S = Saturation (intensité) L = Lightness (luminosité) Pour générer une paire de couleurs à partir d'une couleur, on part d'une couleur principale : 

  Primaire :
  H = 210
  S = 80%
  L = 50%

S : 80% → 50%

On augmente la luminosité :

L : 50% → 75%

Résultat :

Primaire :
hsl(210, 80%, 50%)

Secondaire :
hsl(210, 50%, 75%)
