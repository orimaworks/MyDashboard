Les fonctions

  • calc()
    Effectue un calcul entre différentes unités (+, -, *, /).
    Exemple :
    width: calc(50vw - 20px);
  • min()
    Retourne la plus petite des valeurs fournies.
    Exemple :
    width: min(50vw, 10em, 200px);
  • max()
    Retourne la plus grande des valeurs fournies.
    Exemple :
    width: max(300px, 50vw);
  • clamp()
    Limite une valeur entre un minimum et un maximum.
    Équivalent à max(min, min(valeur, max)).
    Exemple :
    width: clamp(100px, 10em, 200px);

📱 Responsivité (Responsive Design)

  • Définition
    La responsivité est la capacité d'un site web à s'adapter automatiquement aux différentes tailles d'écran (smartphone, tablette, ordinateur...).
  • Mobile First
    Aujourd'hui, la majorité de la navigation se fait sur smartphone. Il est donc recommandé de concevoir d'abord l'interface pour les petits écrans, puis de l'adapter progressivement aux écrans plus larges.
  • Objectifs
    • Améliorer l'UX (User Experience)
    • Faciliter l'accessibilité
    • Optimiser la lisibilité
    • Adapter la disposition des éléments selon l'espace disponible
  • Bonnes pratiques
    • Utiliser des unités relatives (%, vw, vh, rem, em)
    • Éviter les dimensions fixes lorsque c'est possible
    • Utiliser flexbox ou grid
    • Tester sur plusieurs tailles d'écran
  • Media Query
    Permet d'appliquer des règles CSS uniquement sous certaines conditions (largeur, orientation, résolution...). 
    @media (max-width: 768px) {
    /* CSS spécifique mobile */
}

📐 Breakpoints courants (6 tailles)

Type d'écran Largeur
📱 Petit smartphone < 576 px
📱 Grand smartphone 576 à 768 px
📱 Petite tablette 768 à 992 px
💻 Grande tablette 992 à 1200 px
🖥️ PC standard 1200 à 1400 px
🖥️ Grand écran > 1400 px

🎨 Colors

Une couleur HSL se compose de 3 valeurs : hsl(H, S, L) H = Hue (teinte) S = Saturation (intensité) L = Lightness (luminosité) Pour générer une paire de couleurs à partir d'une couleur, on part d'une couleur principale : 

  Primaire :
  H = 210
  S = 80%
  L = 50%

On conserve la teinte (H) car on veut rester dans la même famille. Ensuite on crée une variante : Variante douce (secondaire) On réduit la saturation :

S : 80% → 50%

On augmente la luminosité :

L : 50% → 75%

Résultat :

Primaire :
hsl(210, 80%, 50%)

Secondaire :
hsl(210, 50%, 75%)
