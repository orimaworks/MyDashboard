✨IA Prompt

🎯 Template de prompt efficace

      1. QUI ?
  • 👉 Quel rôle tu veux que l’IA prenne
  • Exemples :
  • - « Agis comme un expert Django »
  • - « Joue le rôle d’un formateur en cybersécurité »
      • 2. **QUOI ?**
  • 👉 Quelle est la tâche demandée _Exemples :_ - « Explique-moi… » - « Analyse ce code… » - « Génère une structure de projet… »
      • 3. **POURQUOI ?**
    👉 À quoi ça sert / Quel est ton objectif réel _Exemples :_ - « Pour que je puisse le réutiliser en production » - « Dans le cadre d’un projet local sur Raspberry Pi »
      4. **POUR QUI ?**
    👉 Ton niveau ou le public visé _Exemples :_ - « Je suis débutant/intermédiaire » - « À destination d’un client non technique »
      5. **COMMENT ?**
    👉 Format attendu _Exemples :_ - « Liste numérotée » - « Tableau » - « Bloc markdown complet avec frontmatter YAML » - « Code commenté ligne par ligne »
      6. **STYLE ?**
    👉 Le ton à adopter _Exemples :_ - « Langage soutenu, clair, sans flatterie » - « Pédagogique mais sans simplifier à l’excès »
      7. **CONTRAINTES ?**
    👉 Ce que tu veux éviter _Exemples :_ - « Pas de markdown » - « Pas de réponse vague ou générique » - « Pas de contenu coupé en plusieurs messages » 
## 🧪 EXEMPLE RAPIDE

> Agis comme un expert PostgreSQL.  
> Génére une base de données pour une application de gestion de films.  
> Objectif : que je puisse l’utiliser dans un projet Django local.  
> Je suis développeur intermédiaire.  
> Format : bloc de code SQL commenté ligne par ligne.  
> Style : pédagogique, direct.  
> Contraintes : pas de texte inutile autour, code uniquement.
