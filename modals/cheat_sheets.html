⭐ Cheat Sheets


💻 Windows

  • Ctrl + Windows + D : créer un nouveau bureau virtuel.
  • Ctrl + Windows + ← : basculer vers le bureau virtuel situé à gauche.
  • Ctrl + Windows + → : basculer vers le bureau virtuel situé à droite.

📄 Office / Outlook

  • Alt + S + S + 1 : accéder à la signature (séquence dépendante de la version d'Outlook).
  • Alt + J + M + S : accéder aux options de signature (séquence dépendante de la version d'Outlook).
  • Alt + S + A + F, puis P : insérer une pièce jointe (séquence dépendante de la version d'Outlook).
  • Ctrl + N : créer un nouvel e-mail.
  • Ctrl + R : répondre à un e-mail.
  • Ctrl + F : transférer un e-mail dans les applications où ce raccourci est affecté à cette action.
  • Ctrl + Y : rétablir une action.

💻 Développement

  • Dans les outils de développement du navigateur, sélectionner un élément HTML avec l'inspecteur, puis ajouter l'attribut suivant à sa balise ouvrante pour rendre son contenu éditable : contenteditable="true".
  • Documentation Python : utiliser une docstring pour documenter une fonction, une classe ou un module. """Description de la fonction."""
  • Frontmatter YAML : bloc de métadonnées placé au début d'un document. 
    ---
title: ""
description: ""
date: ""
---
  • Commentaire sur une ligne Python : # commentaire.
  • Commentaire HTML : <!-- commentaire -->.
  • Commentaire CSS : /* commentaire */.

🗒️ Conventions de nommage

  • Classe : CamelCase.
  • Constante : SNAKE_CASE.
  • Variable ou fonction : snake_case (convention courante en Python).

⌨️ Commande Exécuter (Windows + R)

  • %appdata% : ouvrir le dossier des données itinérantes de l'utilisateur.
  • %localappdata% : ouvrir le dossier des données locales de l'utilisateur.
  • %temp% : ouvrir le dossier temporaire de l'utilisateur.
  • shell:startup : ouvrir le dossier de démarrage automatique de l'utilisateur.
  • optionalfeatures : activer ou désactiver des fonctionnalités Windows.
  • winver : afficher la version de Windows.
  • msinfo32 : afficher les informations système.
  • msconfig : ouvrir la configuration système.
  • taskmgr : ouvrir le Gestionnaire des tâches.
  • devmgmt.msc : ouvrir le Gestionnaire de périphériques.
  • diskmgmt.msc : ouvrir la Gestion des disques.
  • cleanmgr : ouvrir l'outil de nettoyage de disque.
  • services.msc : gérer les services Windows.
  • regedit : ouvrir l'Éditeur du Registre.
  • appwiz.cpl : ouvrir Programmes et fonctionnalités.
  • %userprofile% : ouvrir le dossier du profil utilisateur.
  • C:\ProgramData : accéder au dossier des données communes des programmes.

🌐 Réseau

  • ipconfig : afficher la configuration IP.
  • ipconfig /all : afficher la configuration réseau détaillée.
  • ipconfig /flushdns : vider le cache du résolveur DNS.
  • ping adresse_ip : tester la connectivité vers une adresse IP.
  • netstat -ano : afficher les connexions réseau et les identifiants des processus associés.
  • ncpa.cpl : ouvrir les connexions réseau.

🔒 Sécurité et confidentialité

  • netplwiz : gérer les comptes utilisateur et certaines options de connexion.
  • sfc /scannow : analyser et tenter de réparer les fichiers système protégés (terminal exécuté en administrateur recommandé).
  • secpol.msc : gérer les stratégies de sécurité locale sur les éditions Windows compatibles, notamment Pro.

🛑 Arrêt et redémarrage de Windows

  • shutdown /s /t 0 : arrêter Windows immédiatement.
  • shutdown /r /t 0 : redémarrer Windows immédiatement.
  • shutdown /s /t 60 : programmer l'arrêt de Windows dans 60 secondes.
  • shutdown /a : annuler un arrêt programmé, si le délai le permet.

⚡ Options avancées utiles

  • God Mode : créer un dossier avec le nom suivant pour regrouper de nombreux paramètres système : GodMode.{ED7BA470-8E54-465E-825C-99712043E01C}.
  • taskschd.msc : ouvrir le Planificateur de tâches pour créer des automatisations.

🔳 QR Code dans Word

  • Ctrl + F9 : insérer un champ Word.
  • Dans les accolades générées par Word, saisir le champ suivant pour générer un QR Code à partir d'une URL : 
    { DISPLAYBARCODE "https://exemple.fr" QR \t \h 1000 }
  • Remplacer https://exemple.fr par l'adresse souhaitée, puis mettre à jour le champ pour générer le code-barres.

📝 Créer un fichier RTF avec l'invite de commandes

  • Alt + D : sélectionner la barre d'adresse de l'Explorateur de fichiers.
  • Dans cette barre, saisir cmd, puis valider avec Entrée pour ouvrir l'invite de commandes dans le dossier courant.
  • Exécuter les commandes suivantes pour créer un fichier RTF vide et tenter de l'ouvrir :
echo. > test.rtf
start write test.rtf

Remarque : WordPad n'est plus fourni avec les versions récentes de Windows 11. La commande write peut donc ne pas fonctionner.
