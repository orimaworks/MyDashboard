CSS - Cheat Sheet

🌱 Variables CSS (:root)

  • Déclare des variables réutilisables dans tout le projet.
  • :root { --primary:#0D6EFD; --secondary:#6C757D; --radius:10px; }
  • color: var(--primary);
  • background: var(--secondary, black); (valeur par défaut)

🎨 Couleurs

  • Définit la couleur du texte ou du fond.
  • color: red | #FF0000 | rgb() | rgba() | hsl() | var(--primary);
  • background-color: white;
  • opacity: 0 → 1;

📦 Box Model

  • Gestion des dimensions d'un élément.
  • width, height
  • min-width, max-width
  • padding
  • margin
  • box-sizing: content-box | border-box;

🖼️ Border

  • Définit les bordures.
  • border: 2px solid black;
  • border-style: solid | dashed | dotted | double | groove | ridge | inset | outset | none;
  • border-radius: 5px | 50%;

📝 Texte

  • Mise en forme du texte.
  • font-size
  • font-family
  • font-weight: normal | bold | 100-900;
  • font-style: normal | italic;
  • text-align: left | center | right | justify;
  • text-decoration: none | underline | line-through;
  • text-transform: uppercase | lowercase | capitalize;
  • letter-spacing
  • line-height
  • text-shadow: 0 0 5px lime;

👁️ Affichage

  • Contrôle le rendu.
  • display: block | inline | inline-block | flex | grid | none;
  • visibility: visible | hidden;
  • opacity: 0-1;

📍 Positionnement

  • Position d'un élément.
  • position: static | relative | absolute | fixed | sticky;
  • top right bottom left
  • z-index

📜 Overflow

  • Gestion des débordements.
  • overflow: visible | hidden | auto | scroll;
  • overflow-x
  • overflow-y

🖼️ Images

  • Dimensionnement des images.
  • object-fit: contain | cover | fill | none | scale-down;
  • object-position: center;

🧲 Flexbox

  • Disposition sur un axe.
  • display:flex;
  • flex-direction: row | column | row-reverse | column-reverse;
  • flex-wrap: nowrap | wrap | wrap-reverse;
  • justify-content: flex-start | center | flex-end | space-between | space-around | space-evenly;
  • align-items: stretch | flex-start | center | flex-end | baseline;
  • align-content
  • gap
  • flex-grow
  • flex-shrink
  • flex-basis
  • flex: grow shrink basis;
  • order
  • align-self

🧩 Grid

  • Disposition en lignes et colonnes.
  • display:grid;
  • grid-template-columns
  • grid-template-rows
  • repeat()
  • minmax()
  • fr
  • grid-column
  • grid-row
  • grid-area
  • justify-items
  • align-items
  • place-items
  • gap

🎬 Transformations

  • Déplace ou redimensionne un élément.
  • transform: translate();
  • rotate()
  • scale()
  • skew()

✨ Transitions

  • Animation douce.
  • transition: all .3s ease;
  • linear | ease | ease-in | ease-out | ease-in-out;

🎞️ Animations

  • Animation complète.
  • @keyframes
  • animation-name
  • animation-duration
  • animation-delay
  • animation-iteration-count
  • animation-direction
  • animation-fill-mode

🖱️ Curseur

  • Apparence du pointeur.
  • cursor: pointer | text | grab | move | wait | crosshair | not-allowed;

🌗 Filtres

  • Effets graphiques.
  • filter: blur() brightness() contrast() grayscale() invert() saturate() sepia();
  • backdrop-filter: blur(5px);

💡 Ombres

  • Ajoute du relief.
  • box-shadow: x y blur color;
  • text-shadow: x y blur color;

📱 Responsive

  • Adaptation aux écrans.
  • @media (max-width:768px){ ... }
  • @media (min-width:1024px){ ... }
  • @media (orientation:portrait){ ... }
  • @media (prefers-color-scheme:dark){ ... }
  • @media (prefers-reduced-motion:reduce){ ... }

🖱️ Pseudo-classes

  • Réagit aux interactions.
  • :hover
  • :focus
  • :focus-visible
  • :active
  • :visited
  • :checked
  • :disabled
  • :nth-child()
  • :first-child
  • :last-child
  • :not()

🎭 Pseudo-éléments

  • Ajoute du contenu virtuel.
  • ::before
  • ::after
  • ::first-letter
  • ::first-line
  • ::selection
  • ::placeholder

📏 Unités

  • Les principales unités.
  • px Pixel
  • % Pourcentage
  • em Taille du parent
  • rem Taille racine
  • vw Largeur écran
  • vh Hauteur écran
  • fr Fraction (Grid)
  • auto

🎯 Sélecteurs

  • * Tous les éléments
  • div Balise
  • .card Classe
  • #menu ID
  • div img Descendant
  • div > img Enfant direct
  • div + p Frère adjacent
  • div ~ p Frères suivants
  • [type="text"] Attribut

🚀 Astuces utiles

  • scroll-behavior: smooth;
  • scrollbar-width: none;
  • user-select: none;
  • pointer-events: none;
  • white-space: nowrap;
  • text-wrap: balance;
  • accent-color: lime;
  • aspect-ratio: 16 / 9;
