Assemblage et recherche de données

Gestion d'une erreur de recherche
A (identifiant recherché) B (formule à appliquer) C (résultat obtenu)
1 B9999 =SIERREUR(RECHERCHEV(A1;E2:F3;2;FAUX);"Introuvable") Introuvable

Pour l'exemple RECHERCHEV, le tableau de recherche E2:F3 doit contenir les identifiants en colonne E et les libellés correspondants en colonne F. La recherche exacte est activée par FAUX.


Raccourcis clavier

  • Ctrl + Maj + L : activer ou désactiver les filtres automatiques
  • Ctrl + Shift + 1 : ouvrir la boîte de dialogue Format de cellule
  • Ctrl + L : Créer un tableau
  • Ctrl + Espace : Sélectionner la colonne du tableau
  • Shift + Espace : Sélectionner la ligne du tableau

Insérer ou supprimer des lignes et colonnes

  • Ctrl + Shift + + : ouvrir la boîte de dialogue Insérer des cellules
  • Ctrl + - : ouvrir la boîte de dialogue Supprimer des cellules
  • Alt + L + U + S + D : supprimer la ligne entière

Ajuster la largeur des colonnes et la hauteur des lignes

Sélectionner les lignes ou colonnes à modifier. Pour toute la feuille, utiliser le bouton de sélection situé à l'intersection des en-têtes de lignes et de colonnes.

  • Alt + L + ç + J : Ajuste automatiquement la hauteur
  • Alt + L + ç + A : Ajuste automatiquement la largeur

Trier les données

  • Alt + é + 2 : Ordre Ascendant
  • Alt + é + D + 1 : Ordre Descendant

Navigation et édition

  • F2 : modifier le contenu de la cellule active
  • Ctrl + ← ou →: atteindre le bord de la plage de données dans la direction choisie
  • Ctrl + Début : revenir au début de la feuille
  • Ctrl + Fin : atteindre la dernière cellule utilisée de la feuille
  • : valider la saisie
  • Échap : annuler la saisie en cours

Insérer date ou heure dans une cellule :

  • Ctrl + ; : insérer la date
  • Ctrl + : : insérer l'heure
