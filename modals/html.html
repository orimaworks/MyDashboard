Les fonctions

  • calc()
    Effectue un calcul entre différentes unités (+, -, *, /).
    Exemple :
    width: calc(50vw - 20px);
  • min()
    Retourne la plus petite des valeurs fournies.
    Exemple :
    width: min(50vw, 10em, 200px);
  • max()
    Retourne la plus grande des valeurs fournies.
    Exemple :
    width: max(300px, 50vw);
  • clamp()
    Limite une valeur entre un minimum et un maximum.
    Équivalent à max(min, min(valeur, max)).
    Exemple :
    width: clamp(100px, 10em, 200px);

📝 Champs texte

  • Texte simple
    Champ de saisie standard.
    Attributs utiles :
    id : identifiant unique
    name : nom de la donnée envoyée
    placeholder : texte indicatif
    required : champ obligatoire
    autofocus : focus automatique
    pattern : validation (Regex)
    title : info-bulle et message d'erreur
    Exemple :
                <input type="text"
            id="nom"
            name="nom"
            placeholder="ABC"
            required
            autofocus
            pattern="[A-Za-z]{3,}"
            title="3 caractères minimum">
  • Texte multiligne
    Exemple :
                <textarea
            id="commentaire"
            name="commentaire"
            placeholder="Votre commentaire...">
            </textarea>
  • Email
    Exemple : 
                <input
            type="email"
            name="email"
            placeholder="john.doe@mail.com">
  • URL
    Exemple : 
                <input
            type="url"
            size="50"
            placeholder="https://monsite.fr">
  • Téléphone
    Exemple : 
                <input
            type="tel"
            placeholder="01 02 03 04 05"
            pattern="[0]{1}[1-9]{1}[0-9]{8}">
  • Mot de passe
    Exemple : 
                <input
            type="password"
            pattern="(?=.*\d)(?=.*[a-z])(?=.*[A-Z]).{8,}">
  • Recherche
    Exemple : 
                <input
            type="search"
            placeholder="Rechercher..."
            size="50">

🔢 Champ numérique

  • Nombre

    Exemple :

            type="number"

✅ Choix utilisateur

  • Cases à cocher (Checkbox)
    ✔ Plusieurs choix possibles
    Important : Chaque checkbox possède un name différent.
    <input type="checkbox" name="v1">
    <input type="checkbox" name="v2">
  • Boutons radio
    🔘 Un seul choix possible
    Important : Tous les boutons radio doivent partager le même name.
    <input type="radio" name="genre">
    <input type="radio" name="genre">

  • Liste déroulante


    Exemple : 

                <label for="pays">Pays :</label>
            <select id="pays" name="pays">
            <option value="" disabled selected>— Sélectionnez —</option>
            <option value="fr">France</option>
            <option value="be">Belgique</option>
            <option value="ch">Suisse</option>
            <option value="ca">Canada</option>
            <option value="us">États‑Unis</option>
            </select>
  • Liste avec saisie (datalist) 
                <input list="liste">
            <datalist id="liste">
              <option value="Paris">
              <option value="Lyon">
            </datalist>

    L'attribut list de l'input doit être identique à l' id du datalist.
  • Sélecteur de couleur <input type="color">

  • required → champ obligatoire
  • readonly → lecture seule
  • disabled → désactivé
  • checked → sélectionné par défaut
  • selected → option sélectionnée
  • placeholder → texte d'aide
  • value → valeur par défaut
  • min / max → bornes
  • step → incrément
  • pattern → validation Regex
  • autocomplete → active/désactive l'autocomplétion
  • maxlength → longueur maximale
  • multiple → plusieurs valeurs/fichiers
