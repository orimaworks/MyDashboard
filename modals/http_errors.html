🌐 HTTP Status Codes

Les codes HTTP sont des réponses envoyées par un serveur après une requête. Ils indiquent si la requête a réussi, a été redirigée ou a échoué.

🧩 Structure

        HTTP/1.1 404 Not Found
        │        │
        │        └── Message associé
        └────────── Code de statut
  • 1xx → Information
  • 2xx → Succès
  • 3xx → Redirection
  • 4xx → Erreur côté client
  • 5xx → Erreur côté serveur

🟢 2xx — Succès

Code Signification
200 OK — La requête a réussi.
201 Created — Une ressource a été créée.
204 No Content — Succès sans contenu à retourner. 
        GET /api/users
        → 200 OK

🟡 3xx — Redirections

Ces codes ne sont pas des erreurs : ils demandent simplement au client de consulter une autre URL.

Code Usage
301 Moved Permanently — Redirection définitive.
302 Found — Redirection temporaire (connexion, session...).
304 Not Modified — Le navigateur utilise sa copie en cache.
307 Temporary Redirect — Redirection temporaire en conservant la méthode HTTP.
308 Permanent Redirect — Redirection permanente en conservant la méthode. 
        GET /dashboard
        302 Found
        Location: /login

Ici, le navigateur est automatiquement redirigé vers la page de connexion.

🔴 4xx — Erreurs du client

La requête est comprise par le serveur, mais elle est invalide ou ne peut pas être exécutée.

Code Cause la plus fréquente
400 Bad Request — Paramètres ou syntaxe incorrects.
401 Unauthorized — Authentification requise.
403 Forbidden — Authentifié mais sans autorisation.
404 Not Found — Ressource inexistante.
405 Method Not Allowed — Mauvaise méthode (GET, POST...).
408 Request Timeout — Le client a mis trop de temps à répondre.
409 Conflict — Conflit avec l'état actuel de la ressource.
429 Too Many Requests — Limite de requêtes atteinte.

Exemple 404

        GET /images/logo.png
        404 Not Found

Le serveur fonctionne correctement, mais le fichier demandé n'existe pas.

Exemple 403

        GET /admin
        403 Forbidden

La ressource existe, mais l'utilisateur n'a pas les droits nécessaires.

⚫ 5xx — Erreurs du serveur

Le client n'est généralement pas responsable : le problème provient du serveur ou d'une application.

Code Signification
500 Internal Server Error — Erreur interne de l'application.
501 Not Implemented — Fonction non prise en charge.
502 Bad Gateway — Mauvaise réponse d'un serveur intermédiaire.
503 Service Unavailable — Service indisponible (maintenance, surcharge).
504 Gateway Timeout — Temps d'attente dépassé entre serveurs. 
        POST /api/login
        500 Internal Server Error

La requête est valide, mais l'application a rencontré une erreur inattendue.

🧠 Comment interpréter rapidement un code ?

Famille Question à se poser
2xx La requête a-t-elle réussi ?
3xx Vers quelle URL suis-je redirigé ?
4xx Ai-je demandé la bonne ressource avec les bons droits ?
5xx Le problème vient-il du serveur ou de l'application ?

📋 Mémo des codes indispensables

        200  OK
        201  Created
        204  No Content

        301  Redirection permanente
        302  Redirection temporaire
        304  Cache valide

        400  Mauvaise requête
        401  Non authentifié
        403  Accès interdit
        404  Ressource introuvable
        405  Méthode interdite
        409  Conflit
        429  Trop de requêtes

        500  Erreur interne
        502  Mauvaise passerelle
        503  Service indisponible
        504  Timeout entre serveurs

⚠️ À retenir

  • Un code 3xx n'est généralement pas une erreur mais une redirection.
  • Les 4xx indiquent le plus souvent un problème de requête, d'URL ou de permissions.
  • Les 5xx proviennent du serveur : le client ne peut généralement pas les corriger.
  • Le premier chiffre suffit souvent à orienter immédiatement le diagnostic.
