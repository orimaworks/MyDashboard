Le langage Java

Java est un langage de programmation orienté objet, portable et fortement typé. Il est utilisé pour développer des applications web, des logiciels de bureau, des applications mobiles et des systèmes d'entreprise.


Présentation de Java

Créé par Sun Microsystems en 1995, Java repose sur le principe « Write Once, Run Anywhere » : un programme compilé peut s'exécuter sur différents systèmes disposant d'une machine virtuelle Java (JVM) compatible.

  • Orienté objet : organisation du code à l'aide de classes et d'objets.
  • Portable : exécution sur plusieurs systèmes grâce à la JVM.
  • Fortement typé : les types des variables sont vérifiés par le compilateur.
  • Gestion automatique de la mémoire : le ramasse-miettes (Garbage Collector) libère la mémoire devenue inutilisée.

Installation et vérification

Pour compiler et exécuter des programmes Java, installez un kit de développement Java (JDK).

Vérifier la version du compilateur :

javac -version

Vérifier la version de l'environnement d'exécution :

java -version

Premier programme Java

Voici un exemple simple qui affiche un message dans le terminal :

public class Main {
public static void main(String[] args) {
System.out.println("Bonjour, Java !");
}
}

Enregistrez ce code dans un fichier nommé Main.java.

Compiler le programme :

javac Main.java

Exécuter le programme :

java Main

Résultat attendu :

Bonjour, Java !

Les notions fondamentales

  • Variables et types : int, double, boolean, char et String.
  • Conditions : if, else et switch.
  • Boucles : for, while et do-while.
  • Méthodes : blocs de code réutilisables pour organiser les traitements.
  • Classes et objets : les classes définissent des propriétés et des comportements, et les objets en sont des instances.
  • Exceptions : gestion des erreurs à l'aide de try, catch et finally.
  • Collections : structures comme List, Set et Map.

Outils et environnements de développement

  • JDK : outils nécessaires pour compiler et développer des applications Java.
  • JVM : machine virtuelle qui exécute le bytecode Java.
  • IDE : environnements de développement tels qu'IntelliJ IDEA, Eclipse ou Visual Studio Code avec les extensions Java appropriées.
  • Maven et Gradle : outils de gestion des dépendances et de construction des projets.

Domaines d'utilisation

  • Applications web et services backend.
  • Logiciels d'entreprise et systèmes distribués.
  • Applications Android, selon les outils et technologies employés.
  • Traitement de données et applications cloud.
  • Applications de bureau et outils métier.
