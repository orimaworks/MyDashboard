JavaScript

Fiche de référence JavaScript : syntaxe, types, fonctions, tableaux, objets, DOM, événements, programmation asynchrone et bonnes pratiques.


📌 Déclaration de variables

  • const : déclarer une variable dont la réaffectation est interdite.
  • let : déclarer une variable dont la valeur pourra être réaffectée.
  • var : ancienne syntaxe, généralement à éviter dans le code moderne.
const nom = "Orima";
let age = 30;
age = 31;

Privilégier const par défaut et utiliser let lorsqu'une réaffectation est nécessaire. Un objet déclaré avec const peut toujours être modifié : seule la réaffectation de la variable est interdite.


🔤 Types de données

  • string : chaîne de caractères, par exemple "Bonjour".
  • number : nombre, par exemple 42 ou 3.14.
  • boolean : valeur booléenne, true ou false.
  • undefined : valeur d'une variable déclarée mais non initialisée.
  • null : absence de valeur intentionnelle.
  • bigint : entier de grande taille, par exemple 123n.
  • symbol : identifiant unique utilisé notamment comme clé de propriété.
  • object : objets, tableaux et autres structures de données.
const texte = "Bonjour";
const nombre = 42;
const actif = true;
const vide = null;

console.log(typeof texte);  // "string"
console.log(typeof nombre); // "number"
console.log(typeof actif);  // "boolean"
console.log(typeof vide);   // "object" (particularité historique)

🔍 Opérateurs et comparaisons

  • + : addition numérique ou concaténation de chaînes.
  • -, *, /, % : soustraction, multiplication, division et reste de division.
  • === : égalité stricte, sans conversion implicite de type.
  • !== : différence stricte.
  • >, <, >=, <= : comparaisons.
  • && : ET logique.
  • || : OU logique.
  • ! : négation logique.
  • ?? : valeur de remplacement uniquement si la valeur de gauche est null ou undefined.
  • ?. : accès optionnel à une propriété.
const age = 20;

console.log(age >= 18);          // true
console.log(age === "20");       // false
console.log(null ?? "Inconnu");  // "Inconnu"
console.log(false || "Défaut");  // "Défaut"
console.log(false ?? "Défaut");  // false

🔀 Conditions et opérateur ternaire

  • if / else : exécuter du code selon une condition.
  • switch : sélectionner une branche selon une valeur.
  • ?: : choisir une valeur selon une condition.
const age = 20;

if (age >= 18) {
    console.log("Majeur");
} else {
    console.log("Mineur");
}

const statut = age >= 18 ? "Majeur" : "Mineur";

Le ternaire convient aux choix simples entre deux expressions. Pour une logique complexe, préférer if / else.


🔁 Boucles

  • for : répéter des instructions avec une initialisation, une condition et une évolution.
  • while : répéter tant qu'une condition est vraie.
  • for...of : parcourir les valeurs d'un itérable, comme un tableau.
  • for...in : parcourir les clés énumérables d'un objet.
  • break : interrompre une boucle.
  • continue : passer à l'itération suivante.
const fruits = ["Pomme", "Poire", "Kiwi"];

for (const fruit of fruits) {
    console.log(fruit);
}

Pour parcourir un tableau, privilégier généralement for...of ou une méthode adaptée comme forEach().


⚙️ Fonctions

  • Déclaration classique : fonction nommée, disponible avant sa déclaration dans son périmètre grâce au mécanisme de remontée des déclarations de fonctions.
  • Expression de fonction : fonction affectée à une variable.
  • Fonction fléchée : syntaxe concise, avec un comportement particulier de this.
  • return : renvoyer un résultat et terminer l'exécution de la fonction.
  • Paramètre : variable déclarée dans la signature d'une fonction.
  • Argument : valeur transmise lors de l'appel.
function addition(a, b) {
    return a + b;
}

const multiplier = function (a, b) {
    return a * b;
};

const carre = nombre => nombre ** 2;

console.log(addition(2, 3));    // 5
console.log(multiplier(2, 3));  // 6
console.log(carre(4));          // 16

🧩 Tableaux et méthodes utiles

  • push() : ajouter un élément à la fin.
  • pop() : retirer le dernier élément.
  • includes() : vérifier la présence d'une valeur.
  • find() : récupérer le premier élément correspondant à une condition.
  • filter() : créer un tableau contenant les éléments retenus.
  • map() : créer un tableau transformé.
  • forEach() : exécuter une fonction pour chaque élément.
  • reduce() : accumuler les éléments en une valeur.
  • some() : vérifier si au moins un élément satisfait une condition.
  • every() : vérifier si tous les éléments satisfont une condition.
  • sort() : trier le tableau en place.
  • slice() : extraire une portion sans modifier le tableau original.
  • splice() : ajouter, retirer ou remplacer des éléments dans le tableau original.
const nombres = [1, 2, 3, 4, 5];

const doubles = nombres.map(n => n * 2);
const pairs = nombres.filter(n => n % 2 === 0);
const premierPair = nombres.find(n => n % 2 === 0);
const somme = nombres.reduce((total, n) => total + n, 0);

console.log(doubles);      // [2, 4, 6, 8, 10]
console.log(pairs);        // [2, 4]
console.log(premierPair);  // 2
console.log(somme);        // 15

🧱 Objets et décomposition

  • objet.propriete : accéder à une propriété.
  • objet["propriete"] : accéder à une propriété par une clé dynamique ou textuelle.
  • ... : syntaxe de décomposition ou de regroupement, selon le contexte.
  • Object.keys() : obtenir les clés propres énumérables.
  • Object.values() : obtenir les valeurs propres énumérables.
  • Object.entries() : obtenir les paires clé-valeur.
const utilisateur = {
    nom: "Orima",
    age: 30
};

const { nom, age } = utilisateur;
const copie = { ...utilisateur, actif: true };

console.log(nom);          // "Orima"
console.log(copie.actif);  // true
console.log(Object.keys(utilisateur));

La décomposition avec ... réalise une copie superficielle : les objets imbriqués restent partagés entre la source et la copie.


📝 Chaînes de caractères

  • length : longueur de la chaîne en unités de code UTF-16.
  • trim() : supprimer les espaces en début et en fin.
  • toLowerCase() : convertir en minuscules.
  • toUpperCase() : convertir en majuscules.
  • includes() : rechercher une sous-chaîne.
  • replace() : remplacer la première occurrence correspondante, selon le motif fourni.
  • replaceAll() : remplacer toutes les occurrences correspondantes.
  • split() : découper une chaîne en tableau.
  • slice() : extraire une portion de chaîne.
  • `Texte ${expression}` : insérer une expression dans une chaîne de gabarit.
const nom = " Orima ";
const propre = nom.trim();

console.log(propre.toUpperCase()); // "ORIMA"
console.log(propre.includes("Mar")); // true

const age = 30;
console.log(`Âge : ${age} ans`);

🌐 DOM : manipuler une page HTML

  • document.querySelector() : sélectionner le premier élément correspondant à un sélecteur CSS.
  • document.querySelectorAll() : sélectionner tous les éléments correspondants.
  • document.getElementById() : sélectionner un élément par son identifiant.
  • textContent : lire ou modifier le contenu textuel.
  • innerHTML : lire ou modifier le contenu HTML.
  • classList.add() : ajouter une classe CSS.
  • classList.remove() : retirer une classe CSS.
  • classList.toggle() : ajouter ou retirer une classe selon son état.
  • setAttribute() : définir un attribut HTML.
  • createElement() : créer un élément HTML.
  • append() : ajouter un élément ou du texte à un parent.
const titre = document.querySelector("h1");

if (titre) {
    titre.textContent = "Nouveau titre";
    titre.classList.add("actif");
}

Préférer textContent pour afficher du texte non fiable. Éviter d'injecter des données utilisateur dans innerHTML, car cela peut créer une faille XSS.


🖱️ Événements

  • addEventListener() : enregistrer un gestionnaire d'événement.
  • click : clic sur un élément.
  • input : modification de la valeur d'un champ.
  • change : changement validé d'une valeur selon le type de contrôle.
  • submit : soumission d'un formulaire.
  • event.target : élément à l'origine de l'événement.
  • event.preventDefault() : empêcher le comportement par défaut.
  • event.stopPropagation() : empêcher la propagation de l'événement.
const bouton = document.querySelector("#mon-bouton");

if (bouton) {
    bouton.addEventListener("click", event => {
        console.log("Clic détecté", event.target);
    });
}

⏳ Programmation asynchrone

  • setTimeout() : programmer l'exécution différée d'une fonction.
  • Promise : représenter le résultat futur d'une opération asynchrone.
  • async : déclarer une fonction qui renvoie une promesse.
  • await : attendre le règlement d'une promesse dans un contexte compatible.
  • Promise.all() : attendre la réussite de toutes les promesses fournies ou rejeter dès qu'une échoue.
  • try / catch : intercepter les erreurs, notamment celles d'une opération asynchrone attendue avec await.
async function chargerDonnees() {
    try {
        const reponse = await fetch("/api/donnees");

        if (!reponse.ok) {
            throw new Error(`HTTP ${reponse.status}`);
        }

        const donnees = await reponse.json();
        console.log(donnees);
    } catch (erreur) {
        console.error("Échec du chargement :", erreur);
    }
}

chargerDonnees();

fetch() ne rejette pas automatiquement sa promesse en cas de réponse HTTP telle que 404 ou 500 : vérifier response.ok.


📦 Modules JavaScript

  • export : rendre une fonction, une classe ou une valeur accessible depuis un autre module.
  • export default : définir l'exportation par défaut d'un module.
  • import : importer une valeur exportée.
  • type="module" : charger un script HTML comme module JavaScript.
// calculs.js
export function addition(a, b) {
    return a + b;
}

// app.js
import { addition } from "./calculs.js";

console.log(addition(2, 3)); // 5

Les modules s'exécutent en mode strict et possèdent leur propre portée. Pour les tester dans un navigateur, un serveur HTTP local est généralement préférable à l'ouverture directe d'un fichier avec file://.


🛡️ Gestion des erreurs

  • try : encadrer du code susceptible de lever une exception.
  • catch : traiter une exception interceptée.
  • finally : exécuter un bloc après le traitement, qu'une exception ait eu lieu ou non.
  • throw new Error() : lever une erreur explicite.
  • console.log() : afficher une information de débogage.
  • console.warn() : afficher un avertissement.
  • console.error() : afficher une erreur.
  • console.table() : afficher des données tabulaires dans la console.
  • debugger : interrompre l'exécution si les outils de développement autorisent le débogage.
function diviser(a, b) {
    if (b === 0) {
        throw new Error("Division par zéro impossible.");
    }

    return a / b;
}

try {
    console.log(diviser(10, 0));
} catch (erreur) {
    console.error(erreur.message);
}

🧠 Concepts essentiels

  • Portée (scope) : zone dans laquelle un identifiant est accessible.
  • Closure : fonction qui conserve l'accès aux variables de son environnement lexical.
  • Hoisting : mécanisme de traitement des déclarations avant l'exécution du code.
  • Callback : fonction transmise à une autre fonction pour être appelée ultérieurement ou selon une condition.
  • Promesse : objet représentant une opération qui peut être en attente, réussie ou rejetée.
  • Event loop : mécanisme qui coordonne l'exécution du code, les tâches et les callbacks asynchrones.
  • Mutation : modification d'un objet ou d'un tableau existant.
  • Immutabilité : principe consistant à éviter de modifier directement les données existantes.
  • Programmation fonctionnelle : approche privilégiant notamment les fonctions pures et les transformations de données.

✨ Bonnes pratiques

  • Privilégier const, puis let lorsque nécessaire ; éviter var dans le code moderne.
  • Utiliser === et !== pour éviter les conversions implicites non souhaitées.
  • Donner des noms explicites aux variables et fonctions.
  • Écrire des fonctions courtes avec une responsabilité identifiable.
  • Éviter les variables globales inutiles.
  • Préférer les méthodes de tableau adaptées à l'intention : map() pour transformer, filter() pour sélectionner et find() pour rechercher un élément.
  • Traiter les erreurs et vérifier les réponses des appels réseau.
  • Ne jamais considérer une donnée reçue du navigateur ou d'un serveur comme fiable sans validation appropriée.
  • Ne pas confondre une copie superficielle avec une copie profonde.
  • Utiliser les outils de développement du navigateur pour inspecter la console, le DOM, les requêtes réseau et les points d'arrêt.
