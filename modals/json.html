JSON

JavaScript Object Notation — format léger d'échange de données, facile à lire et à écrire pour les humains et les machines.


📝 Structure de base

JSON est construit sur deux structures :

  • Une collection de paires nom/valeur — objet enveloppé dans {}
  • Une liste ordonnée de valeurs — tableau enveloppé dans []

Exemple minimal :

{
"nom": "Orima", "version": 2.0 }

🔤 Types de données

JSON prend en charge six types de données :

  • string — chaîne de caractères entre guillemets doubles
  • number — nombre (sans guillemets)
  • object — collection structurée {}
  • array — liste ordonnée []
  • boolean — true ou false
  • null — valeur vide

Exemples :

{
"texte": "chaîne", "nombre": 42, "actif": true, "vide": null, "liste": [1, 2, 3], "objet": {"clé": "valeur"} }

⚙️ Syntaxe et règles

  • Toujours utiliser des guillemets doubles " pour les chaînes
  • Ne pas mettre de virgule après le dernier élément
  • Ne pas inclure de commentaires natifs
  • Respecter la casse (true ≠ True)
  • Les clés doivent toujours être des chaînes

Exemple invalide :

{
"nom": "test", // Commentaire interdit valeur: "error" // Clé sans guillemets }

🛠️ Validation

Outils de validation recommandés :

  • JSONLint — validateur en ligne
  • JSON Formatter — formatage et validation
  • jq — outil CLI Unix

Commande jq :

cat fichier.json | jq '.'

Raccourcis clavier :

  • Ctrl + S : sauvegarder le fichier
  • Ctrl + Shift + P : ouvrir la palette de commandes (éditeurs)

💾 Bonnes pratiques

  • Utiliser utf-8 comme encodage
  • Formater avec indentation pour la lisibilité
  • Valider contre un schéma (JSON Schema) pour les projets complexes
  • Éviter les données sensibles en clair (mots de passe, tokens)
  • Minifier (compact) pour la production si nécessaire
