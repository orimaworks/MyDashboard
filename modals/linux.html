Linux

Navigation et gestion des fichiers

  • Afficher les fichiers et dossiers du répertoire courant : 
    ls          # Affichage simple
                                                ls -l       # Affichage détaillé
                                                ls -a       # Inclut les fichiers cachés
                                                ls -lah     # Affichage détaillé et tailles lisibles
  • Afficher le chemin du répertoire courant : pwd
  • Changer de répertoire : cd /chemin/du/dossier
  • Remonter d'un niveau : cd ..
  • Revenir au répertoire personnel : cd ~
  • Ouvrir le répertoire courant dans l'explorateur graphique : xdg-open .
  • Créer un dossier : mkdir mon_dossier
  • Créer les dossiers parents si nécessaire : mkdir -p parent/enfant
  • Créer un fichier vide : touch fichier.txt
  • Copier un fichier : cp source.txt copie.txt
  • Copier un dossier et son contenu : cp -r dossier1 dossier2
  • Déplacer ou renommer un fichier : mv ancien.txt nouveau.txt
  • Supprimer un fichier : rm fichier.txt
  • Supprimer avec confirmation : rm -i fichier.txt
  • Supprimer un dossier et son contenu : rm -r dossier
  • Afficher le contenu d'un fichier : cat fichier.txt
  • Afficher un fichier page par page : less fichier.txt
  • Modifier un fichier dans le terminal : nano fichier.txt
  • Afficher l'aide d'une commande : commande --help
  • Consulter le manuel d'une commande : man commande

Renommer des fichiers en boucle

  • Retirer le premier caractère du nom de chaque élément du répertoire courant : 
    for file in ./*; do
                                                                                                                                                                                                                                                    [ -e "$file" ] || continue
                                                                                                                                                                                                                                                        name="${file#./}"
                                                                                                                                                                                                                                                            mv -- "$file" "${name#?}"
                                                                                                                                                                                                                                                            done

    Attention : cette commande modifie réellement les noms. Vérifie les résultats attendus avant de l'exécuter. Elle retire le premier caractère du nom, y compris pour les noms qui ne commencent pas par un point.

  • Afficher les fichiers dont le nom commence par un point : ls -d .[^.]*
  • Renommer un fichier en supprimant son préfixe connu : 
    mv -- ".mon_fichier.txt" "mon_fichier.txt"

Recherche et traitement de fichiers

  • Rechercher un fichier par son nom : 
    find /home -name "index.html"
  • Rechercher sans tenir compte des majuscules : 
    find /home -iname "*.pdf"
  • Rechercher dans le répertoire courant : 
    find . -type f -name "*.txt"
  • Rechercher un texte dans des fichiers : grep -n "texte" fichier.txt
  • Rechercher récursivement dans un dossier : grep -Rni "texte" dossier/
  • Compter les lignes d'un fichier : wc -l fichier.txt
  • Afficher les premières lignes : head -n 10 fichier.txt
  • Afficher les dernières lignes : tail -n 10 fichier.txt
  • Suivre les nouvelles lignes d'un journal : tail -f fichier.log

Permissions et utilisateurs

  • Afficher l'utilisateur courant : whoami
  • Afficher les permissions et propriétaires : ls -l
  • Ajouter le droit d'exécution à un script : chmod +x script.sh
  • Définir les permissions à 755 : chmod 755 script.sh
  • Définir les permissions à 644 : chmod 644 fichier.txt
  • Modifier le propriétaire : sudo chown utilisateur fichier.txt
  • Modifier récursivement le propriétaire d'un dossier : 
    sudo chown -R utilisateur:utilisateur dossier/
  • Afficher les groupes de l'utilisateur : groups

Informations système et ressources

  • Afficher le noyau et les informations système : uname -a
  • Afficher la version de la distribution : 
    cat /etc/os-release
  • Afficher l'espace disque disponible : df -h
  • Afficher la taille des dossiers et fichiers : du -sh *
  • Afficher la mémoire utilisée et disponible : free -h
  • Afficher les processus et leur consommation : top
  • Afficher la durée depuis le dernier démarrage : uptime
  • Afficher la date et l'heure : date
  • Afficher les derniers démarrages : last -x reboot

Installation et gestion des logiciels

  • Actualiser la liste des paquets : sudo apt update
  • Mettre à jour les paquets installés : sudo apt upgrade
  • Mettre à jour le système Debian/Raspberry Pi OS : 
    sudo apt update && sudo apt full-upgrade
  • Installer un logiciel : sudo apt install nom_du_paquet
  • Désinstaller un logiciel : sudo apt remove nom_du_paquet
  • Supprimer également les dépendances devenues inutiles : sudo apt autoremove
  • Rechercher un paquet : apt search nom_du_paquet
  • Afficher les paquets installés correspondant à un nom : dpkg -l "*nom*"

Commandes réseau

  • Afficher les adresses IP : ip a
  • Afficher les routes réseau : ip route
  • Afficher l'adresse IP locale : hostname -I
  • Tester la connectivité : ping -c 4 example.com
  • Afficher les connexions et ports en écoute : ss -tulpn
  • Télécharger le contenu d'une URL dans le terminal : curl https://example.com
  • Télécharger un fichier avec son nom distant : curl -O https://example.com/fichier.zip
  • Tester la résolution DNS : getent hosts example.com
  • Afficher le nom de la machine : hostname

Matériel et stockage

  • Afficher les informations du processeur : lscpu
  • Afficher la mémoire : free -h
  • Lister les périphériques de stockage : lsblk
  • Afficher les systèmes de fichiers et leurs UUID : lsblk -f
  • Afficher les partitions montées : findmnt
  • Afficher les périphériques PCI : lspci (si disponible)
  • Afficher les périphériques USB : lsusb (si disponible)
  • Afficher un résumé du matériel : sudo lshw -short (si installé)
  • Afficher un rapport système détaillé : installer inxi, puis exécuter inxi -Fxz

Processus et services

  • Afficher les processus : ps aux
  • Rechercher un processus : pgrep -a nom
  • Arrêter un processus par son PID : kill PID
  • Demander l'arrêt forcé d'un processus : kill -9 PID (en dernier recours)
  • Afficher l'état d'un service : systemctl status nom.service
  • Démarrer un service : sudo systemctl start nom.service
  • Arrêter un service : sudo systemctl stop nom.service
  • Activer un service au démarrage : sudo systemctl enable nom.service
  • Consulter les journaux d'un service : journalctl -u nom.service

🐧 Linux / Raspberry Pi

  • Afficher la température du Raspberry Pi : vcgencmd measure_temp (si disponible)
  • Afficher les informations du firmware et du matériel : vcgencmd version (si disponible)
  • Afficher les périphériques USB : lsusb (si installé)
  • Afficher l'adresse IP : hostname -I
  • Redémarrer le système : sudo reboot
  • Éteindre proprement le système : sudo shutdown now
  • Consulter la configuration Raspberry Pi : sudo raspi-config (si disponible)
  • Vérifier l'état du système de fichiers : df -h

Alias et variables d'environnement

  • Créer un alias pour la session courante : alias ll='ls -lah'
  • Supprimer un alias : unalias ll
  • Afficher les variables d'environnement : printenv
  • Afficher la valeur d'une variable : echo "$HOME"
  • Ajouter temporairement un dossier au PATH : 
    export PATH="$PATH:$HOME/bin"

Raccourcis du terminal

  • Ctrl + C : interrompre la commande en cours
  • Ctrl + D : envoyer une fin d'entrée ou fermer le terminal interactif
  • Ctrl + L : nettoyer l'affichage du terminal
  • Ctrl + R : rechercher dans l'historique des commandes
  • ↑ / ↓ : parcourir l'historique des commandes
  • Tab : compléter un nom de fichier ou une commande

Remarques importantes

  • Les commandes précédées de sudo s'exécutent avec des privilèges élevés.
  • Les commandes rm, chmod et chown peuvent avoir des effets importants, surtout avec l'option -R.
  • Les commandes et paquets disponibles varient selon la distribution Linux et les logiciels installés.
  • Pour en savoir plus sur une commande : man nom_commande.
