Linux

Retrouve les commandes essentielles pour naviguer dans le système, gérer les fichiers, consulter les processus et administrer un environnement Linux.


Navigation dans le système

  • pwd : afficher le chemin du répertoire courant.
  • ls : lister les fichiers et dossiers.
  • ls -l : afficher les éléments avec leurs détails et leurs permissions.
  • ls -a : afficher également les fichiers cachés.
  • ls -la : afficher tous les éléments, y compris les fichiers cachés, avec leurs détails.
  • cd dossier : accéder à un répertoire.
  • cd .. : remonter au répertoire parent.
  • cd ~ : revenir au répertoire personnel.
  • xdg-open . : ouvrir le répertoire courant dans l'explorateur de fichiers, si un environnement graphique est disponible.
  • clear : nettoyer l'affichage du terminal.
  • history : afficher l'historique des commandes.

Gestion des fichiers et dossiers

  • touch fichier.txt : créer un fichier vide ou actualiser sa date de modification.
  • mkdir dossier : créer un répertoire.
  • mkdir -p parent/enfant : créer une arborescence de répertoires.
  • cp source destination : copier un fichier.
  • cp -r dossier1 dossier2 : copier un répertoire et son contenu.
  • mv source destination : déplacer ou renommer un fichier ou un dossier.
  • rm fichier.txt : supprimer un fichier.
  • rm -r dossier : supprimer récursivement un dossier et son contenu.
  • rm -ri dossier : demander confirmation avant les suppressions récursives.
  • rmdir dossier : supprimer un répertoire vide.
  • cat fichier.txt : afficher le contenu d'un fichier texte.
  • less fichier.txt : consulter un fichier page par page.
  • nano fichier.txt : ouvrir un fichier dans l'éditeur de texte Nano.

Renommer des fichiers cachés en fichiers ordinaires

  • Création d'une boucle pour agir sur l'intégralité des fichiers d'un dossier 
            for file in .*; do
        mv "$file" "${file#.}"
        done

  • Liste les fichiers et dossiers dans le répertoire actuel : 
            ls          #affichage simple
        ls -l       #affichage détaillé
        ls -a       #affichage des fichiers cachés

  • Supprimer un dossier et son contenu : 
            rm -r dossier   #Supprime tout 
        rm -i           #Demande une confirmation avant suppression

    • Recherche de fichiers et de contenu

    • find . -name "*.txt" : rechercher les fichiers TXT dans le répertoire courant et ses sous-répertoires.
    • grep "texte" fichier.txt : rechercher une chaîne de caractères dans un fichier.
    • grep -Rni "texte" dossier/ : rechercher récursivement un texte sans tenir compte de la casse, en affichant les numéros de ligne.
    • which python3 : afficher le chemin de l'exécutable trouvé dans le PATH.
    • command -v python3 : identifier la commande utilisée par le shell.

    Permissions, utilisateurs et exécution

    • whoami : afficher le nom de l'utilisateur courant.
    • ls -l : consulter les permissions et les propriétaires des fichiers.
    • chmod +x script.sh : rendre un script exécutable.
    • chmod 644 fichier.txt : donner au propriétaire les droits de lecture et d'écriture, et aux autres le droit de lecture.
    • chmod 755 script.sh : donner au propriétaire les droits de lecture, d'écriture et d'exécution, et aux autres les droits de lecture et d'exécution.
    • chown utilisateur fichier.txt : modifier le propriétaire d'un fichier, sous réserve des droits nécessaires.
    • sudo commande : exécuter une commande avec les privilèges administrateur autorisés.
    • ./script.sh : exécuter un script situé dans le répertoire courant, si les permissions et l'interpréteur le permettent.

    Gestion des paquets — Debian, Ubuntu, Zorin OS et Raspberry Pi OS

    • sudo apt update : actualiser les listes de paquets disponibles.
    • sudo apt upgrade : installer les mises à jour des paquets installés.
    • sudo apt update && sudo apt upgrade : actualiser les listes puis mettre à jour les paquets.
    • sudo apt install nom_paquet : installer un paquet.
    • sudo apt remove nom_paquet : désinstaller un paquet sans demander systématiquement la suppression de ses fichiers de configuration.
    • sudo apt autoremove : supprimer les dépendances devenues inutiles selon APT.
    • apt search mot_cle : rechercher un paquet dans les dépôts configurés.
    • apt show nom_paquet : consulter les informations d'un paquet.

    Processus et ressources système

    • ps aux : afficher les processus en cours.
    • top : surveiller les processus et l'utilisation des ressources en temps réel.
    • htop : afficher une vue interactive des processus, si l'outil est installé.
    • kill PID : envoyer le signal SIGTERM au processus identifié par son PID.
    • kill -9 PID : envoyer le signal SIGKILL, sans laisser au processus la possibilité de terminer proprement.
    • free -h : afficher l'utilisation de la mémoire.
    • df -h : consulter l'espace utilisé et disponible sur les systèmes de fichiers montés.
    • du -sh dossier/ : afficher la taille totale d'un répertoire.
    • uptime : afficher la durée de fonctionnement et la charge moyenne du système.

    Réseau et connexions

    • ip addr ou ip a : afficher les interfaces réseau et leurs adresses IP.
    • ip route : consulter la table de routage.
    • hostname -I : afficher les adresses IP associées à la machine.
    • ping -c 4 192.168.1.1 : envoyer quatre requêtes ICMP à une adresse IP.
    • ping google.com : tester la connectivité vers un nom de domaine, si la résolution DNS fonctionne.
    • ss -tulpn : afficher les sockets TCP et UDP en écoute, avec les informations de processus accessibles selon les privilèges.
    • curl -I https://example.com : consulter les en-têtes HTTP d'une réponse.
    • curl https://example.com : afficher le contenu renvoyé par l'URL, selon la réponse du serveur.
    • ssh utilisateur@192.168.1.98 : ouvrir une connexion SSH vers la machine distante, si le service est installé et accessible.
    • scp fichier.txt utilisateur@192.168.1.98:/chemin/ : copier un fichier vers une machine distante via SSH.

    Services et journaux système

    • systemctl status nom_service : consulter l'état d'un service géré par systemd.
    • sudo systemctl start nom_service : démarrer un service.
    • sudo systemctl stop nom_service : arrêter un service.
    • sudo systemctl restart nom_service : redémarrer un service.
    • sudo systemctl enable nom_service : activer le démarrage automatique du service.
    • journalctl -u nom_service : consulter les journaux d'un service.
    • journalctl -f : suivre les nouveaux messages du journal système.
    • dmesg : consulter les messages du noyau, sous réserve des restrictions d'accès configurées.

    Archives et compression

    • tar -czf archive.tar.gz dossier/ : créer une archive compressée au format gzip.
    • tar -xzf archive.tar.gz : extraire une archive tar compressée avec gzip.
    • tar -tf archive.tar.gz : lister le contenu d'une archive sans l'extraire.
    • zip -r archive.zip dossier/ : créer une archive ZIP, si l'outil est installé.
    • unzip archive.zip : extraire une archive ZIP, si l'outil est installé.

    Informations sur le système et le matériel

    • uname -a : afficher des informations sur le noyau et le système.
    • lscpu : afficher les informations sur le processeur.
    • lsblk : afficher les périphériques de stockage en mode bloc.
    • lsblk -f : afficher les systèmes de fichiers et les points de montage des périphériques de stockage.
    • sudo lshw : afficher une description détaillée du matériel, si lshw est installé.
    • sudo lshw -short : afficher une liste résumée du matériel.
    • sudo lshw -class processor : afficher les informations matérielles du processeur.
    • sudo apt install inxi, puis inxi -Fxz : installer inxi puis afficher un rapport détaillé sur le système et le matériel.
    • sudo apt install hwinfo, puis sudo hwinfo : installer hwinfo puis afficher un rapport détaillé sur le matériel.

    Raccourcis et aide

    • Tab : compléter automatiquement une commande ou un chemin lorsque c'est possible.
    • Ctrl + C : interrompre la commande en cours dans un terminal interactif, généralement en envoyant SIGINT.
    • Ctrl + L : nettoyer l'affichage du terminal dans les shells courants.
    • ↑ / ↓ : parcourir l'historique des commandes.
    • man nom_commande : consulter le manuel d'une commande.
    • nom_commande --help : afficher l'aide intégrée, lorsqu'elle est disponible.
    • whatis nom_commande : afficher une brève description issue des pages de manuel indexées.
    • alias : afficher les alias définis dans le shell.
    • alias ll='ls -la' : créer un alias pour raccourcir une commande dans le shell courant.

    Commandes utiles sur Raspberry Pi

    • hostname -I : afficher l'adresse IP de la machine.
    • sudo reboot : redémarrer le système.
    • sudo shutdown now : arrêter le système immédiatement.

    Précautions importantes

    • rm -r : supprime récursivement des fichiers et des répertoires. Vérifie toujours le chemin avant exécution.
    • sudo : accorde des privilèges élevés à une commande. Ne l'utilise pas systématiquement.
    • chmod -R et chown -R : modifient récursivement les permissions ou les propriétaires. Une mauvaise cible peut perturber le fonctionnement du système.
    • Les commandes de suppression en terminal ne passent généralement pas par une corbeille et peuvent être irréversibles.
    • Avant d'exécuter une boucle de renommage ou une commande destructive, vérifie le répertoire courant et les fichiers ciblés.
