PowerShell

🧭 Les commandes fondamentales à connaître

  • Découvrir les commandes
    Get-Command — Liste les commandes connues de PowerShell.
  • Rechercher une commande
    Get-Command *process* — Recherche les commandes dont le nom contient "process".
  • Voir l'aide
    Get-Help Get-Process — Affiche l'aide d'une commande.
  • Voir des exemples
    Get-Help Get-Process -Examples — Affiche des exemples d'utilisation.
  • Afficher les propriétés d'un objet
    Get-Process | Get-Member — Permet de découvrir les propriétés et méthodes disponibles.
  • Connaître le type d'une commande
    Get-Command Get-Process — Indique notamment s'il s'agit d'un Alias, Function, Cmdlet, Application, etc.
  • Voir les verbes PowerShell
    Get-Verb — Liste les verbes utilisés pour nommer les cmdlets.

💡 Le trio à retenir

Get-Command
    Get-Help
Get-Member

Get-Command → Quelles commandes existent ?
Get-Help → Comment les utiliser ?
Get-Member → Qu'est-ce que contient l'objet retourné ?

⌨️ Travailler sans souris

  • Complétion automatique
    Tab — Complète automatiquement les commandes, paramètres et chemins.
  • Historique précédent
    ↑ — Rappelle la commande précédente.
  • Historique suivant
    ↓ — Parcourt l'historique dans l'autre sens.
  • Recherche dans l'historique
    Ctrl + R — Recherche une commande déjà utilisée.
  • Interrompre une commande
    Ctrl + C — Arrête la commande en cours.
  • Effacer l'écran
    Clear-Host ou cls — Nettoie l'affichage.
  • Historique
    Get-History — Affiche les commandes précédemment exécutées.
  • Réexécuter une commande de l'historique
    Invoke-History 5 — Réexécute l'entrée numéro 5.

📂 Navigation dans les dossiers

  • Dossier courant
    Get-Location — Affiche le répertoire courant.
  • Changer de dossier
    Set-Location C:\Users\Mario\Documents
  • Raccourci de Set-Location
    cd C:\Users\Mario\Documents
  • Retour au dossier précédent
    Pop-Location
  • Mémoriser le dossier courant
    Push-Location C:\Temp — Change de dossier tout en mémorisant l'ancien.
  • Afficher le contenu
    Get-ChildItem — Liste fichiers et dossiers.
  • Alias classique
    dir ou ls — Alias de Get-ChildItem.
  • Afficher les fichiers cachés
    Get-ChildItem -Force
  • Rechercher récursivement
    Get-ChildItem -Recurse
  • Rechercher un type de fichier
    Get-ChildItem -Recurse -Filter *.pdf

📁 Ouvrir l'Explorateur Windows depuis PowerShell

  • Ouvrir le dossier courant
    explorer .
  • Ouvrir un dossier précis
    explorer C:\Users\Mario\Documents
  • Version PowerShell
    ii . — ii est l'alias de Invoke-Item.

Depuis PowerShell :

🧩 Les commandes accessibles via le PATH

Le PATH contient une liste de dossiers dans lesquels Windows recherche les programmes lorsqu'on tape leur nom sans fournir leur chemin complet.

Afficher le PATH :

$env:Path

Afficher chaque dossier sur une ligne :

$env:Path -split ';'

Exemple : 

C:\Windows\System32
    C:\Windows
    C:\Program Files\Git\cmd
C:\Users\Mario\AppData\Local\Microsoft\WindowsApps

🔎 Lister les programmes exécutables

Get-Command -CommandType Application

Cela permet de rechercher les applications exécutables que PowerShell peut trouver directement.

Pour afficher la description de chaque programme : 

    Get-Command -CommandType Application | Select-Object Name, @{Name='Description'; Expression={ 
      (Get-Item $_.Source).VersionInfo.FileDescription
  }}

📍 Savoir quel programme sera exécuté

Get-Command git
    Get-Command python
    Get-Command notepad
Get-Command winget

Cette commande indique notamment le chemin du programme trouvé.

Pour utiliser l'utilitaire Windows where.exe :

where.exe git

Attention : where est également un alias PowerShell. Utiliser where.exe permet donc d'appeler explicitement l'utilitaire Windows.

📄 Créer et manipuler des fichiers

  • Créer un fichier
    New-Item fichier.txt -ItemType File
  • Créer un dossier
    New-Item MonDossier -ItemType Directory
  • Copier
    Copy-Item fichier.txt copie.txt
  • Déplacer
    Move-Item fichier.txt C:\Temp
  • Renommer
    Rename-Item ancien.txt nouveau.txt
  • Supprimer
    Remove-Item fichier.txt
  • Supprimer un dossier et son contenu
    Remove-Item dossier -Recurse
  • Tester l'existence
    Test-Path C:\Temp\fichier.txt

⚠️ Remove-Item -Recurse -Force peut supprimer beaucoup de données. Toujours vérifier le chemin avant de l'utiliser.

📖 Lire et écrire du texte

  • Lire un fichier
    Get-Content fichier.txt
  • Lire uniquement les premières lignes
    Get-Content fichier.txt -Head 10
  • Lire les dernières lignes
    Get-Content fichier.txt -Tail 10
  • Écrire dans un fichier
    "Bonjour" | Set-Content fichier.txt
  • Ajouter du contenu
    "Nouvelle ligne" | Add-Content fichier.txt
  • Rechercher du texte
    Select-String "erreur" fichier.log
  • Rechercher récursivement
    Get-ChildItem -Recurse | Select-String "erreur"

🔗 Le pipeline |

Le pipeline permet d'envoyer le résultat d'une commande vers une autre. PowerShell transmet principalement des objets, et non simplement du texte. 

Get-Process | Where-Object CPU -gt 100
    Get-Process | Sort-Object CPU -Descending
    Get-Process | Select-Object Name, CPU
Get-Service | Where-Object Status -eq "Running"

🔍 Filtrer

Get-Process | Where-Object CPU -gt 100

Version avec la variable automatique $_ :

Get-Process | Where-Object { $_.CPU -gt 100 }

📋 Sélectionner des propriétés

Get-Process | Select-Object Name, CPU, Id

↕️ Trier

Get-Process | Sort-Object CPU -Descending

📊 Regrouper

Get-Process | Group-Object Company

🔢 Compter / mesurer

Get-ChildItem | Measure-Object

🧮 Opérateurs

-eq       égal
    -ne       différent
    -gt       supérieur
    -ge       supérieur ou égal
    -lt       inférieur
    -le       inférieur ou égal
    -like     correspondance avec *
    -match    expression régulière
    -in       appartient à une liste
    -contains contient une valeur
    -and      ET logique
    -or       OU logique
-not      négation

Exemples :

$age -ge 18

    $name -eq "Mario"

    $file.Name -like "*.pdf"

    $extension -in ".jpg", ".png", ".gif"

($age -ge 18) -and ($country -eq "France")

⚙️ Processus

  • Get-Process — Liste les processus.
  • Get-Process chrome — Recherche un processus précis.
  • Get-Process | Sort-Object CPU -Descending — Trie par CPU.
  • Stop-Process -Name notepad — Arrête un processus.
  • Stop-Process -Id 1234 — Arrête un processus par PID.
  • Start-Process notepad — Lance une application.

⚠️ Stop-Process -Force force l'arrêt du processus.

🔧 Services Windows

  • Get-Service — Liste les services.
  • Get-Service | Where-Object Status -eq "Running" — Services actifs.
  • Get-Service -Name Spooler — Service précis.
  • Start-Service Spooler — Démarre un service.
  • Stop-Service Spooler — Arrête un service.
  • Restart-Service Spooler — Redémarre un service.
  • Set-Service Spooler -StartupType Automatic — Configure le démarrage.

💻 Informations système

  • $PSVersionTable — Version de PowerShell et informations associées.
  • Get-ComputerInfo — Informations détaillées sur Windows et le PC.
  • Get-CimInstance Win32_OperatingSystem — Informations sur le système d'exploitation.
  • Get-CimInstance Win32_Processor — Informations sur le processeur.
  • Get-CimInstance Win32_LogicalDisk — Informations sur les disques logiques.

💾 Disques et volumes

  • Get-PSDrive — Liste les lecteurs PowerShell.
  • Get-Volume — Liste les volumes.
  • Get-Disk — Liste les disques physiques.
  • Get-Partition — Liste les partitions.

⚠️ Les commandes de modification de partitions ou de disques peuvent entraîner une perte de données. Les utiliser uniquement en comprenant précisément leur effet.

🌐 Réseau

  • Get-NetIPConfiguration — Configuration IP.
  • Get-NetAdapter — Cartes réseau.
  • Test-Connection 192.168.1.1 — Test de connectivité, similaire au ping.
  • Test-NetConnection google.com — Test réseau.
  • Test-NetConnection google.com -Port 443 — Teste un port TCP.
  • Resolve-DnsName google.com — Résolution DNS.
  • Get-NetTCPConnection — Connexions TCP.
  • Get-DnsClientServerAddress — Serveurs DNS configurés.

🌍 HTTP / API

  • Invoke-WebRequest https://example.com — Effectue une requête HTTP et récupère notamment le contenu de la réponse.
  • Invoke-RestMethod https://api.example.com — Pratique pour interroger des API REST.

Pour une API JSON, Invoke-RestMethod convertit généralement automatiquement la réponse JSON en objets PowerShell.

📦 JSON

  • $objet | ConvertTo-Json — Convertit un objet PowerShell en JSON.
  • Get-Content data.json | ConvertFrom-Json — Convertit du JSON en objet PowerShell.

🛠️ Logiciels avec WinGet

winget est le gestionnaire de paquets Windows. Il peut être utilisé directement depuis PowerShell.

  • winget search firefox — Recherche un logiciel.
  • winget install Mozilla.Firefox --exact — Installe un logiciel identifié précisément.
  • winget list — Liste les logiciels détectés par WinGet.
  • winget upgrade — Recherche les mises à jour disponibles.
  • winget upgrade --all — Met à jour les paquets pris en charge.
  • winget uninstall Mozilla.Firefox — Désinstalle un logiciel identifié.
  • winget show Mozilla.Firefox — Affiche les informations d'un paquet.

⚠️ WinGet ne garantit pas la gestion de tous les logiciels installés. Pour certains programmes, il faudra utiliser leur propre programme de désinstallation ou leur installeur.

🧠 Comprendre les objets PowerShell

C'est l'un des concepts les plus importants de PowerShell. Une commande ne renvoie généralement pas simplement du texte : elle renvoie des objets. 

$processus = Get-Process

    $processus[0].Name
    $processus[0].Id
$processus[0].CPU

Pour découvrir ce qu'un objet contient : 

Get-Process | Get-Member

On peut ensuite enchaîner les opérations : 

Get-Process |
    Where-Object CPU -gt 100 |
    Sort-Object CPU -Descending |
Select-Object -First 10 Name, CPU, Id

🧪 Exemple de workflow PowerShell

Rechercher les gros fichiers PDF d'un dossier : 

Get-ChildItem C:\Documents -Recurse -Filter *.pdf |
    Where-Object Length -gt 10MB |
    Sort-Object Length -Descending |
Select-Object FullName, Length

Exporter le résultat : 

Get-ChildItem C:\Documents -Recurse -Filter *.pdf |
    Where-Object Length -gt 10MB |
    Sort-Object Length -Descending |
    Select-Object FullName, Length |
Export-Csv gros-pdf.csv -NoTypeInformation

📌 Alias courants

PowerShell possède de nombreux alias. Ils sont pratiques pour travailler rapidement, mais il est préférable d'apprendre les noms complets des cmdlets. 

    cd      → Set-Location
    pwd     → Get-Location
    dir     → Get-ChildItem
    ls      → Get-ChildItem
    cp      → Copy-Item
    mv      → Move-Item
    rm      → Remove-Item
    cat     → Get-Content
    cls     → Clear-Host
    echo    → Write-Output

Pour connaître les alias : 

Get-Alias

Et pour connaître l'origine d'un alias : 

Get-Alias cd
    Get-Alias ls
Get-Alias dir

🎯 La logique à retenir

Pour apprendre PowerShell efficacement, pense toujours dans cet ordre : 

1. Je cherche une commande
 ↓
 Get-Command

 2. Je regarde comment elle fonctionne
 ↓
 Get-Help

 3. J'examine ce qu'elle retourne
 ↓
 Get-Member

 4. Je filtre
 ↓
 Where-Object

 5. Je sélectionne
 ↓
 Select-Object

 6. Je trie
 ↓
 Sort-Object

 7. J'enchaîne
 ↓
|

Exemple : 

Get-Process |
    Where-Object CPU -gt 50 |
    Sort-Object CPU -Descending |
Select-Object -First 10 Name, CPU
