Raspberry Pi OS

Commandes de référence pour administrer un Raspberry Pi 5 sous Raspberry Pi OS : configuration matérielle, stockage, réseau, services, GPIO et maintenance système.


Identification du système

  • cat /etc/os-release : afficher la distribution et sa version.
  • cat /etc/debian_version : afficher la version de base Debian.
  • uname -a : afficher les informations sur le noyau Linux et l'architecture.
  • uname -m : identifier l'architecture du processeur, par exemple aarch64 en 64 bits.
  • hostnamectl : afficher le nom de la machine et les informations système disponibles.
  • vcgencmd version : afficher la version du firmware VideoCore, si l'outil est disponible.

Mises à jour et configuration

  • sudo apt update : actualiser les listes de paquets.
  • sudo apt full-upgrade : appliquer les mises à jour en autorisant les changements de dépendances nécessaires.
  • sudo apt autoremove : supprimer les dépendances devenues inutiles.
  • sudo raspi-config : ouvrir l'outil de configuration Raspberry Pi, lorsqu'il est installé.
  • sudo reboot : redémarrer le Raspberry Pi.
  • sudo poweroff : arrêter proprement le système avant de couper son alimentation.

Température et performances du Pi 5

  • vcgencmd measure_temp : afficher la température du SoC, si la commande est disponible.
  • vcgencmd get_throttled : consulter les indicateurs de limitation thermique, de tension et leurs historiques.
  • vcgencmd measure_clock arm : afficher la fréquence actuelle du domaine d'horloge ARM, si elle est exposée par le firmware.
  • free -h : consulter l'utilisation de la RAM et de la mémoire d'échange.
  • uptime : afficher la durée de fonctionnement et la charge moyenne.
  • top : surveiller les processus et leur consommation de ressources.
  • watch -n 2 vcgencmd measure_temp : actualiser la température toutes les deux secondes, si vcgencmd est disponible.

Stockage — microSD et SSD NVMe

  • lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINTS,MODEL : afficher les périphériques de stockage, leurs partitions et leurs points de montage.
  • df -hT : consulter l'espace utilisé et disponible sur les systèmes de fichiers.
  • sudo fdisk -l : afficher les disques et leurs partitions.
  • findmnt : afficher les systèmes de fichiers montés.
  • ls -l /dev/nvme* : vérifier la présence de fichiers de périphériques NVMe, si le SSD est détecté.
  • sudo nvme list : lister les SSD NVMe, si le paquet nvme-cli est installé et si le périphérique est accessible.
  • sudo smartctl -a /dev/nvme0 : consulter les données SMART d'un contrôleur NVMe, si smartmontools est installé et le périphérique correctement identifié.
  • sudo blkid : afficher les UUID et les types de systèmes de fichiers.

Réseau et accès distant

  • hostname -I : afficher les adresses IP de la machine.
  • ip addr : consulter les interfaces réseau et leurs adresses.
  • ip route : afficher la route par défaut et les autres routes.
  • nmcli device status : afficher l'état des interfaces gérées par NetworkManager, s'il est utilisé.
  • rfkill list : consulter l'état des blocages des interfaces radio, si l'outil est installé.
  • sudo raspi-config : configurer notamment les options d'interface disponibles, dont SSH selon la version.
  • sudo systemctl status ssh : vérifier l'état du serveur SSH.
  • sudo systemctl enable --now ssh : activer et démarrer le serveur SSH, s'il est installé.
  • ssh utilisateur@adresse_ip : se connecter au Pi depuis un autre appareil disposant d'un client SSH.
  • ss -tulpn : consulter les ports en écoute et les processus associés lorsque les permissions le permettent.

Services et journaux

  • systemctl --type=service --state=running : lister les services actifs.
  • systemctl status nom_service : consulter l'état d'un service.
  • sudo systemctl restart nom_service : redémarrer un service.
  • sudo systemctl enable nom_service : activer son démarrage automatique.
  • journalctl -b : consulter les journaux du démarrage actuel.
  • journalctl -p err -b : afficher les erreurs du démarrage actuel.
  • journalctl -u nom_service -f : suivre les journaux d'un service en temps réel.
  • systemctl --failed : lister les unités en échec.

GPIO et matériel électronique

  • pinout : afficher le brochage GPIO du Raspberry Pi, si la commande est disponible.
  • pinctrl : consulter ou configurer l'état des broches GPIO avec l'outil fourni pour le Raspberry Pi 5.
  • ls /dev/gpiochip* : rechercher les périphériques GPIO exposés par le noyau.
  • gpiodetect : lister les contrôleurs GPIO, si les outils libgpiod sont installés.
  • gpioinfo : consulter les lignes GPIO et leurs informations, si les outils libgpiod sont installés.
  • i2cdetect -y 1 : rechercher les périphériques sur le bus I²C numéro 1, si I²C est activé et les outils installés.
  • ls /dev/spidev* : vérifier la présence des périphériques SPI, si SPI est activé.

Attention : le Raspberry Pi 5 utilise un contrôleur RP1 pour une partie de ses entrées-sorties. Les anciennes méthodes fondées sur certains outils GPIO historiques ne sont pas toutes compatibles. Ne relie jamais une broche GPIO directement à une tension de 5 V : les entrées GPIO fonctionnent en logique 3,3 V.


USB, périphériques et bus

  • lsusb : afficher les périphériques USB détectés.
  • lsusb -t : afficher l'organisation des périphériques USB et les vitesses de connexion.
  • lspci : afficher les périphériques PCI, si l'outil est installé et des périphériques sont exposés.
  • lsblk : afficher les périphériques de stockage détectés.
  • dmesg --follow : suivre les nouveaux messages du noyau, notamment lors du branchement d'un périphérique.

Partage de fichiers et Samba

  • systemctl status smbd : vérifier l'état du service Samba.
  • testparm -s : vérifier et afficher la configuration Samba effective, si Samba est installé.
  • smbclient -L localhost : lister les partages visibles localement, si le client Samba est installé.
  • sudo systemctl restart smbd : redémarrer le service Samba après une modification de configuration.
  • journalctl -u smbd -b : consulter les journaux du service Samba.

Python et environnement de développement

  • python3 --version : afficher la version de Python 3.
  • python3 -m venv .venv : créer un environnement virtuel Python dans le dossier courant, si le module venv est installé.
  • source .venv/bin/activate : activer l'environnement virtuel dans le shell courant.
  • deactivate : quitter l'environnement virtuel actif.
  • python3 -m pip --version : vérifier la disponibilité de pip pour Python 3.
  • git --version : vérifier l'installation de Git.
  • git status : consulter l'état du dépôt Git courant.
  • python3 manage.py runserver 0.0.0.0:8000 : démarrer un serveur de développement Django accessible sur les interfaces réseau, si le projet et ses dépendances sont configurés.

Le serveur de développement Django ne doit pas être exposé directement à Internet. Pour un accès distant, privilégie un VPN ou un tunnel SSH et configure correctement le pare-feu.


Arrêt, redémarrage et maintenance

  • sudo reboot : redémarrer le Pi proprement.
  • sudo poweroff : arrêter le système proprement.
  • systemctl list-timers : consulter les minuteries systemd actives.
  • journalctl --disk-usage : consulter l'espace utilisé par les journaux persistants.
  • sudo journalctl --vacuum-time=7d : supprimer les anciens journaux archivés de plus de sept jours, sans supprimer les entrées du journal actif.

Précautions spécifiques au Raspberry Pi 5

  • Utilise une alimentation adaptée au Pi 5 et aux périphériques connectés. Un SSD NVMe et les périphériques USB peuvent augmenter la consommation électrique.
  • Avant de retirer l'alimentation, arrête proprement le système pour limiter les risques de corruption des données.
  • Avant toute opération sur un disque, vérifie son nom avec lsblk. Les noms de périphériques peuvent varier d'une configuration à l'autre.
  • Les commandes vcgencmd, pinctrl, raspi-config et les outils GPIO dépendent des paquets installés et de la version du système.
  • Les options de configuration et les chemins peuvent différer entre Raspberry Pi OS Bookworm et les versions ultérieures.
