VSCode

    Général

  • Ctrl + K, puis Ctrl + S : ouvrir le panneau des raccourcis clavier
  • Ctrl + Shift + P : ouvrir la palette de commandes
  • Ctrl + P : rechercher et ouvrir rapidement un fichier
  • Ctrl + Shift + F : rechercher du texte dans tous les fichiers du projet
  • Ctrl + F : rechercher du texte dans le fichier courant
  • Ctrl + H : rechercher et remplacer du texte dans le fichier courant

    Édition

  • Ctrl + S : enregistrer le fichier
  • Ctrl + Z : annuler la dernière action
  • Ctrl + Y : rétablir la dernière action annulée
  • Ctrl + X : couper la ligne courante si aucune sélection n'est effectuée
  • Ctrl + C : copier la ligne courante si aucune sélection n'est effectuée
  • Alt + ↑ / ↓ : déplacer la ligne courante vers le haut ou le bas
  • Shift + Alt + ↑ / ↓ : dupliquer la ligne vers le haut ou le bas
  • Ctrl + Shift + K : supprimer la ligne courante
  • Fn / End : aller au début ou à la fin de la ligne
  • Ctrl + Home / End : aller au début ou à la fin du fichier
  • Ctrl + Entrée : insérer une ligne en dessous de la ligne courante
  • Ctrl + Shift + Entrée : insérer une ligne au-dessus de la ligne courante

    Sélection multiple

  • Ctrl + D : sélectionner la prochaine occurrence du texte sélectionné
  • Ctrl + Shift + L : sélectionner toutes les occurrences du texte sélectionné
  • Alt + clic : ajouter un curseur à l'emplacement du clic
  • Ctrl + Alt + ↑ / ↓ : ajouter un curseur sur la ligne supérieure ou inférieure
  • Esc : quitter le mode de sélection multiple

    Formatage et navigation

  • Shift + Alt + F : formater automatiquement le document entier
  • Ctrl + K, puis Ctrl + F : formater la sélection
  • F12 : accéder à la définition d'une fonction, variable ou méthode
  • Alt + ← / → : revenir à l'emplacement précédent ou suivant
  • Ctrl + G : accéder à une ligne précise
  • Ctrl + / : commenter ou décommenter une ligne
  • Ctrl + K puis Ctrl + C : commenter un bloc
  • Ctrl + K puis Ctrl + U : décommenter un bloc
  • Ctrl + Espace : afficher les suggestions de code disponibles

    Affichage

  • Ctrl + B : afficher ou masquer la barre latérale
  • Ctrl + J : afficher ou masquer le panneau inférieur
  • Ctrl + + / - : agrandir ou réduire le zoom de l'interface, selon les raccourcis configurés
